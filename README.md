## 📚 About This Repository

This repository contains my learning journey while understanding **Git and GitHub** from the basics.

The purpose of this repository is to practice Git commands, understand version control concepts, and learn how developers manage and collaborate on software projects using Git and GitHub.

## 🎯 What I Am Learning

Throughout this tutorial, I am learning:

- Git installation and configuration
- Creating Git repositories
- Tracking files with Git
- Staging and committing changes
- Viewing Git history
- Working with branches
- Switching between branches
- Merging branches
- Git rebase
- Git tags
- Git clone
- Git push and pull
- Working with remote repositories
- `.gitignore`
- Resolving merge conflicts
- Basic GitHub workflow
